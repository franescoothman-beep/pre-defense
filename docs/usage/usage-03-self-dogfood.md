### 最可能一问就崩的点

- **同一批 claims 复算时，抽取环节靠什么固定模型输出？温度、种子、结构化约束分别怎么设的？**
  - 为什么：本场两次被问均未答出确定性机制，考生对该点没有可陈述的实现细节，一问即空。
  - 怎么改：在 §3.7 补一段：抽取调用固定 temperature=0、固定 prompt 版本号、zod 校验失败重试上限，并给出同一批 claims 连跑 N 次 risk_score 完全一致的实测记录。
- **懒加载之后你测过几个 worker 并发写 WAL？锁等待时长和写失败率各是多少？**
  - 为什么：本场两次回答都落到无关的统计模型上，考生手里没有并发压测数据，追问一层就崩。
  - 怎么改：补一张压测表：worker 数 1/2/4/8 下的锁等待毫秒数与写失败率，并说明懒加载前后同一指标的对比，明确根因是否消除。
- **你自查出的正是可复现性问题，那这次自查本身别人怎么原样复现出同样三条结论？**
  - 为什么：本场回答只承诺补做数据划分，未交代评测集版本与运行流程，自指缺口原样暴露。
  - 怎么改：在 §4.3 写明自查所用评测集的 commit 或版本号、运行命令、模型与参数，并附三条结论各自的判定依据与命中位置。
- **C17 只有换材料的 delta，同一材料重复评测的对照组在哪里？怎么排除分差来自模型自身波动？**
  - 为什么：材料未设同材料重复评测对照组，一旦被问就只剩单侧对比，结论的排他性站不住。
  - 怎么改：补一组同一材料重复评测 N 次的 delta 分布作为基线，与换材料时的 delta 并列成表，说明两者量级差异。
- **1774 字、0 乱码只来自一份 PDF，换双栏、表格或扫描件还成立吗？**
  - 为什么：样本量为 1，考生无法给出跨排版证据，追问具体排版类型即无数据可答。
  - 怎么改：把样本扩到至少 5 份覆盖单栏、双栏、含表格、含页眉页脚的中文 PDF，逐份列出字数与乱码数，并注明失败样本。
- **y 容差 2.5 是怎么定出来的？双栏或表格排版下会不会把正常空格也删掉？**
  - 为什么：阈值只给单一取值且仅一份样本验证，缺少标定过程与反例，追问边界条件即无依据。
  - 怎么改：补阈值扫描：y 容差取 1.5/2.0/2.5/3.0 时的取文本正确率，并给出双栏与表格样本上的误删空格计数。
- **5 分制的锚点怎么定义？评分者间一致性或与人工标注的一致性怎么验证的？**
  - 为什么：材料只写了评分档位形式，没有锚点定义与一致性数据，被问评分可信度时无据可依。
  - 怎么改：在 §4 补 1–5 分每档的文字锚点各一句，并给出与人工标注的 Spearman 相关或 Kappa 值及样本量。
- **三位 AI 评委的质询质量怎么评估？有没有和人工评审或基线模型对照过？**
  - 为什么：材料未交代评委质量评估方式，而整份报告的可信度依赖于此，一问就牵动全局。
  - 怎么改：补一小节：同一材料下 AI 评委与 1–2 位人工评委的质询点重合率，或与基线模型的追问命中率对照表。

### 总建议

三个维度的问题在本场指向同一件事：材料把"机制已实现"写成了结论，却没有留下可被第三方复算的痕迹。逻辑链上，确定性主张与 LLM 抽取的不确定性之间缺固定手段；证据上，多处结论只有单份样本或单侧对比；深度上，懒加载与容差阈值都停在"改了"而没有"测到什么程度"。三者叠加，评委只要沿任一链条追问一层就会落到同一处空白。下一场最该练的不是补话术，而是把每个主张配一条可复算的记录：命令、参数、样本清单、指标数值，四件套齐了再上场。另外，考生在被问实现细节时反复滑向统计模型与现实意义，这是答非所问的高频模式，需专门做"先复述问题、再给数据、最后给边界"的三段式应答训练。
